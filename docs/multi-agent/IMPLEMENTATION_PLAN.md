## 现状清单

| 子系统 | 真实能力 | 当前边界 |
|---|---|---|
| 账号与隔离 | FastAPI JWT、账号级知识库/文档/会话/学习记录隔离、注册登录限流、账户删除 | 个人画像只含姓名、学校、专业、年级与目标时长；没有学段/学科/学习目标字段 |
| 资料库与 RAG | PDF/DOCX/TXT/Markdown 解析、分块、FastEmbed、Qdrant、Cross-Encoder、证据阈值、引用原文、SSE | 依赖后端 OpenAI 兼容 LLM 配置；RAG 已独立真实运行，不应复制一套检索流程 |
| 课程/图谱/路径 | SQLAlchemy 模型、迁移、课程目录、用户掌握度、先修边、路径偏好 | 部分首页展示及演示页面仍可能读静态演示数据；后端目录数据来自初始课程种子 |
| 错题/变式练习 | 错题按账号存储；变式生成要求三题、去重与答案格式校验；提交后服务端判分 | 变式生成依赖真实模型；模型错误明确返回失败，不应替换成假题 |
| 测验/计划/分析 | 后端测验判分、计划、学习时段与账号分析 API 已存在 | 自动画像建议和证据化解释尚未形成统一入口 |
| 多智能体 | 原项目无 Agent Harness SDK、协议或调用示例 | 增加有界的后端角色适配器和调度 API；AgentHarness 运行时未确认前只报告状态，不伪称已连接 |
| CodeArts | 项目仓库中未见 CodeArts 配置 | 提供按 Vue/FastAPI 的仓库、检查、构建、测试、制品和部署落地指南；云资源未配置前不声称已发布 |

## 主要差距与实施顺序

1. 用统一任务合同与调度器连接资料问答、通用答疑、错题变式、画像建议和图谱分析。
2. 复用现有 RAG 检索、证据拒答、引用、SSE、课程图谱、掌握度、错题、计划与权限数据；不创建第二套学习数据模型。
3. 将学段、学习学科和目标加入账号画像；兼容旧用户的空字段，并由学生编辑、跳过或拒绝建议。
4. 为调用设置意图白名单、输入长度限制、每用户速率限制、并发上限、超时、一次重试、隐私安全日志及错误关闭。
5. 补充架构/数据隐私/CodeArts/容器部署/本地启动/演示文档与自动化测试。
6. 运行已有测试、前端类型检查与构建；报告实际结果和外部依赖。

## 版本边界

此实施目标是可在本地验证的应用内多智能体调度层。AgentHarness 的名称存在多个互不兼容的产品/项目；本机 `AGENTHARNESS_API` 只是凭证配置，没有匹配的产品方、Base URL、协议或 Agent ID。未完成产品身份及 API 契约核验前，不把该凭证发送到任何网络地址。调度器仍可用后端现有模型 Provider 和业务 Agent 执行已确认的路径，并将 AgentHarness 状态显示为未验证。
