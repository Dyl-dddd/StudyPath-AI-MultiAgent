# 计算机软件著作权登记材料要求与准备清单

整理日期：2026-10-21

## 一、登记申请通常需要的材料

根据国家版权局《计算机软件著作权登记办法》第九至十二条，申请材料包括：

1. 按中国版权保护中心要求在线填写的软件著作权登记申请表。
2. 软件鉴别材料：源程序和一种文档（如用户手册、设计说明书）。通常分别提交前、后各连续 30 页；总页数不足 60 页的提交全部。除规定例外外，源程序每页不少于 50 行，文档每页不少于 30 行。
3. 申请人身份证明。个人申请准备有效身份证明；单位申请准备有效主体证明并按要求盖章。
4. 权属相关证明：存在委托开发、合作开发、职务开发、原软件改编、转让、继承等情况时，按实际情况准备合同、任务书、许可或权利承受证明。没有此类情形时，不应虚构证明材料。

申请表使用中文，签字/盖章须与申请人名称一致，申请材料按要求采用 A4 规格。北京市政务服务网当前办事指南还提示申请表在线打印、A4 纵向单面打印、源程序和文档黑白打印、各部分单独连续编页；实际办理按申请人所在地及中心系统当时的要求核对。官方规则允许对鉴别材料选择例外交存方式；涉及代码保密时，提交前应根据官方现行办理指南选择适用方式。

## 四、提交前必须核实

- 软件全称、简称、版本号在申请表、源程序页眉、文档页眉中完全一致。
- 软件名称应与代码注释、截图、说明书、网站/产品中实际使用名称相协调；若申请表与签章名称不一致，准备可证明关系的材料。
- 申请主体应为实际著作权人，需核实是否存在合作开发、职务开发、委托开发或第三方代码/素材授权约束。
- “开发完成日期”“首次发表日期/未发表”应依据真实开发记录填写，不要从当前操作日期推算或编造。
- 源程序打印稿应从申报版本生成，并检查是否泄露令牌、密钥、数据库内容、用户信息、上传资料或其他敏感配置。
- 本目录文件是申请准备材料；官方在线申请表及登记系统的最终格式要求优先。
