## 软件的主要功能（可直接填写申请表）

智学研途 AI 个性化学习平台是一款面向课程学习场景的应用软件，采用浏览器访问方式，为学习者提供课程资料管理、知识梳理、学习任务安排、练习复习和智能问答等功能。用户可注册、登录并进入个人学习空间，维护个人资料和学习偏好，查看课程目录、课程内容及课程知识图谱。知识图谱以节点和关系呈现课程知识点及其先修联系，便于学习者了解知识结构和学习顺序。平台支持查看课程学习进度与知识点掌握情况，并结合学习计划、测验结果和错题记录呈现学习状态，帮助用户安排后续学习任务。用户可浏览课程题目、参加测验并查看作答结果，系统保存测验记录；答错的题目可纳入错题复习，用户可查看、更新相关记录。学习计划功能用于创建、查看和调整待办学习事项，专注学习记录及学习统计用于回顾阶段性学习情况。平台提供个人知识库管理功能，用户可创建知识库并上传 PDF、DOCX、TXT 或 Markdown 文档；系统对支持的文件进行内容提取、文本分块和索引处理，并显示处理状态。用户可在 AI 学习问答页面选择知识库并提出问题，系统根据检索到的资料片段生成回答，在界面展示来源引用及原文片段，便于核对答案依据；当检索证据不足或模型服务不可用时，系统按照配置返回相应提示或错误信息。平台还提供会话历史查看和管理、文档预览与删除、课程内容维护等功能。软件将账号、课程学习记录、测验、错题、计划及知识库相关数据保存在服务端，并按用户账号进行隔离；页面在无数据或请求失败时显示相应状态。通过上述功能，平台将课程学习、学习过程记录、资料检索与 AI 辅助答疑整合在一个统一的学习工作空间中。

## 简要功能摘要

智学研途 AI 个性化学习平台是一套面向课程学习场景的 Web 软件，提供课程学习、知识图谱、个性化学习路径、练习测验、错题复习、学习计划和数据分析，并支持个人资料库管理及带来源引用的 RAG 智能问答。扫描件 OCR 和 LLM 问答依赖部署环境配置。
