# 智学研途 AI 个性化学习平台演示视频讲解稿

适用场景：软件作品演示视频　　建议时长：约 7—9 分钟　　版本：2026-10-23

## 录制前准备

1. 提前确认前端、后端、账号登录、资料上传、资料问答和大模型问答都能正常使用。
2. 准备一份可公开展示、包含二叉搜索树与操作系统分页知识的学习资料。上传后等到文档状态显示“已就绪”，再开始录屏。
3. 录屏时使用已准备好的测试账号；登录过程不口述、不展示密码。确认账号中有课程、学习计划以及至少一道错题，或录制时现场完成一道答错的练习。
4. 当前示例配置的模型服务为 DashScope 上的 `deepseek-v4-pro-0813`。视频中可说“DeepSeek V4 Pro 系列模型 API”，不要把 API 密钥或服务端配置画面录进去。
5. 逐个功能展示完整页面：首页先展示上半部，再向下滚动展示图谱、课程和计划；提问后留出时间让回答和引用完整显示；测验时至少提交一次答案，错题本和变式题要展示实际结果。

## 视频脚本

### 片头与登录｜约 20 秒

【画面】打开系统登录页，填写已准备好的账号并登录。鼠标移动简洁，避免录入密码的过程进入成片。

【讲解】

大家好，接下来我演示“智学研途 AI 个性化学习平台”。系统面向日常课程学习，整合了学习总览、个人资料库、课程知识图谱、个性化学习路径、智能练习、错题复测和学习计划等功能。首先登录学习者账号，进入个人学习空间。

### 首页学习总览｜约 50 秒

【画面】登录后展示“学习总览”首页顶部；指向统计卡片和个性化复习建议。再向下滚动到图谱预览、课程列表和近期学习计划。

【讲解】

登录后进入首页。首页集中展示当前账号的学习状况，包括今日专注时长、间隔复测掌握情况、本周任务完成进度和连续测验天数。页面中的数据来自当前账号已经保存的学习记录；例如当前账号有一道待复习错题，首页就会给出对应的复习提示。

继续向下，可以看到课程知识图谱预览、正在学习的课程和近期学习计划。学生能够从这里继续课程、打开完整图谱、进入计划，也可以直接上传资料。这样，学习状态、课程入口和下一步任务都集中在一个页面中。

### 上传资料与建立知识库｜约 45 秒

【画面】点击“上传资料”或进入左侧“学习资料库”；选择或新建“数据结构”知识库；上传准备好的学习资料，展示文档进入处理状态，再展示“已就绪”。

【讲解】

下面我先准备个人学习资料。进入学习资料库后，可以按课程或主题创建自己的知识库，并自定义知识库名称。这里我使用“数据结构”作为示例，上传一份包含二叉搜索树内容的资料。

文件上传后，系统会在后端解析文本、切分内容并建立检索索引。文档显示“已就绪”后，才可以稳定地用于资料问答。资料库与课程题库是不同的数据来源：这里上传的文件用于个人资料检索，课程目录和课程练习由课程内容提供。

### 基于个人资料的 RAG 问答｜约 65 秒

【画面】进入“AI 智能答疑”，确认当前选中“数据结构”知识库和资料问答模式。输入：“为什么二叉搜索树的中序遍历结果递增？”发送问题；等待完整回答；依次指向回答和右侧参考来源，打开一条来源核对原文。

【讲解】

接下来演示基于个人资料的智能答疑。我在知识库问答模式中提出：“为什么二叉搜索树的中序遍历结果递增？”

系统会先在当前账号选定的知识库范围内检索相关资料片段，再对候选内容排序，并检查是否有足够证据支持回答。检索到可靠依据后，才调用大模型结合上下文组织答案，同时在右侧列出参考文档和对应片段。点击来源可以回到原文核对，因此回答与用户上传资料之间有明确对应关系。

从数据处理看，当前项目使用中文文本嵌入、Qdrant 向量检索和重排，再通过兼容 OpenAI 接口的模型服务生成回答。这段流程属于 RAG，也就是检索增强生成。它让回答尽量围绕用户选定的学习资料，而不是只给一个没有出处的通用解释。

### 通用大模型问答｜约 45 秒

【画面】在问答页面切换到“大模型”模式，展示模式说明后输入：“仔细讲讲操作系统中的分页知识。”发送并等待回答。

【讲解】

同一个问答页面还提供“大模型”模式。我切换到这个模式，提出：“仔细讲讲操作系统中的分页知识。”

这个模式直接调用当前配置的大模型，根据模型已有知识进行讲解，不会检索刚才上传的本地资料，也不会提供个人资料引用。本次演示环境通过 DashScope API 调用 DeepSeek V4 Pro 系列模型。两种模式各有用途：针对上传讲义、需要核对原文时使用知识库问答；希望获得通用概念讲解时使用大模型模式。

### 我的课程、课程目录与知识图谱｜约 70 秒

【画面】点击“V2 首页预览”简单展示学习卡片，再点击“我的课程”；选择“操作系统”，打开课程目录弹窗；指向章节、知识点和掌握度；点击“打开课程知识图谱”。

【讲解】

现在回到 V2 首页预览，并打开“我的课程”。这里列出当前账号可以学习的课程卡片，卡片上可以查看课程分类、当前章节、目录知识点数量和个人进度。

点击“查看课程目录”，可以展开具体章节和知识点。每个条目都显示节点类型和当前账号的掌握情况，学生可以据此判断下一步要学什么。选择“打开课程知识图谱”，就能把课程节点、章节和知识点之间的联系可视化。

图谱中，课程主题与具体知识点通过关联线连接；维护好的先修关系还可以帮助学生理解学习顺序。点击节点可以进一步查看对应内容，课程目录、图谱和练习入口由此衔接起来。

### 个性化学习路径与自主调整｜约 55 秒

【画面】进入“个性化学习路径”；展示推荐步骤、建议先学/重点巩固标记、推荐理由和前置知识；演示调整步骤顺序或勾选，然后点击保存或加入学习计划。

【讲解】

接着查看个性化学习路径。系统综合课程知识图谱、当前账号掌握度和错题复习状态，推荐先修知识、重点巩固内容和后续学习步骤，并说明推荐原因。

路径是辅助建议，最终安排由学生自己决定。学生可以根据自己的考试时间和学习目标调整步骤顺序，保留需要的知识点，再将选定内容加入学习计划。比如系统发现分页知识点有错题记录，就可以优先建议复习相关概念；掌握情况更新后，也可以重新生成路线。

### 随堂检测与错题本｜约 70 秒

【画面】进入“智能练习与测验”，选择“操作系统”、整门课程随机练习和 3 题；开始测验并完成作答。至少将一道题故意答错后提交，展示结果提示。随后进入“错题本”，找到刚才的题目，展示题干、错因/解析，再点击“原题 + 变式复测”。

【讲解】

路径确定后，我来做一次随堂检测。这里选择“操作系统”，练习范围设为整门课程随机练习，题量选择 3 题。系统会根据课程题库生成本次练习，学生逐题作答后提交。

提交后，系统展示答题结果和解析。答错的题目会关联到相应课程与知识点，并进入当前账号的错题本。现在我打开刚才答错的题目，可以看到题目内容、错误记录和复习入口。

选择“原题 + 变式复测”，系统围绕同一个知识点生成不同情境的题目。变式题不只是重复原题，而是改变题目条件或提问方式，检查学生能否迁移解题方法。完成后再提交，系统根据结果继续更新错题复习状态，帮助学生反复练习直到真正掌握。

### 学习数据分析与用户画像｜约 40 秒

【画面】打开“学习数据分析”，切换近 7 天/近 30 天；指向测验次数、任务完成、学习时长、正确率趋势、错题复习状态和需要关注的知识点。

【讲解】

完成练习后，打开学习数据分析。这里把当前账号的测验、学习任务、专注记录和错题复习状态汇总起来。可以切换统计周期，观察测验次数、平均正确率和需要重点关注的知识点。

这些记录共同构成学习画像，并为后续复习建议和学习路径提供依据。首次使用或记录较少时，图表可能还不完整；随着真实学习活动持续保存，分析结果会逐步丰富。

### 自定义我的学习计划｜约 45 秒

【画面】打开“我的学习计划”；切换日期/列表视图；新建或编辑一项任务，设置所属课程、日期和优先级；展示保存后的任务卡片及完成勾选。

【讲解】

最后打开“我的学习计划”。学生可以按日期添加学习任务，设置关联课程、计划时间和优先级，也可以切换列表或日历查看安排。系统推荐的路径可以加入计划，但学生仍然可以自行修改任务内容、时间和优先级。

例如，临近考试的重点知识可以设置较高优先级；已经掌握的内容则可以安排间隔复习。任务完成后更新状态，首页和学习分析会读取已保存的计划与学习记录。至此，资料准备、课程学习、智能练习、错题复测和计划管理形成了完整的学习闭环。

### 结尾｜约 15 秒

【画面】回到首页，短暂停留后结束录制。

【讲解】

以上就是智学研途 AI 个性化学习平台的主要功能演示。系统将课程、个人资料、知识图谱、个性化路径、智能练习和学习计划连接起来，帮助学生根据自己的学习情况安排下一步学习。谢谢观看。

## 录制时的操作检查清单

- 首页：上半部指标和复习建议、下半部图谱预览/课程/计划都要录到。
- 资料问答：知识库选对、文档已就绪、回答完整显示、至少打开一条引用。
- 通用大模型：明确切换“大模型”模式，解释它不检索本地资料。
- 课程与图谱：展示课程卡片、目录掌握度、完整图谱节点关系。
- 学习路径：展示推荐原因，并实际调整/保存至少一步。
- 检测与错题：现场提交测验，确认错题出现，再打开变式练习页面。
- 数据分析：等统计图表加载完成后再讲数据，数值以录制时当前账号实际显示为准。
- 学习计划：现场新增或修改一项任务，并展示优先级保存结果。
- 保密：不要拍到密码、API Key、管理员令牌、浏览器开发者工具或本地 `.env` 文件。

## 技术表述核对

当前项目依赖和代码中可核对到的实现是：FastAPI 后端、OpenAI 兼容 SDK、Qdrant（本地持久化或远程）向量存储、FastEmbed 中文嵌入及重排组件；当前运行配置模型标识为 `deepseek-v4-pro-0813`，服务地址是 DashScope。项目依赖清单中没有 LangChain 或 Chroma，因此正式录制时不建议称“本系统使用 LangChain 和 Chroma”，除非你已在实际部署中另行替换或接入这两项组件。

DeepSeek 官方 API 文档目前列出的模型 ID 包括 `deepseek-v4-pro` 和 `deepseek-flash`；你本地运行环境使用的是 DashScope 上的 `deepseek-v4-pro-0813` 标识，视频里建议表述为“当前演示环境通过 DashScope API 调用 DeepSeek V4 Pro 系列模型”，避免将平台侧模型标识说成官方 DeepSeek API 的模型 ID。
